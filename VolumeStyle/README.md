# تحكم الصوت الزجاجي — مشروع Android أصلي

تطبيق Android حقيقي يعترض أزرار الصوت الفعلية في الهاتف ويعرض شريط صوت
زجاجي مخصص بدلاً من شريط النظام الافتراضي، بنفس الطريقة التي تعمل بها
تطبيقات مثل "Volume Styles".

## كيف يعمل
- `VolumeKeyAccessibilityService.kt`: خدمة Accessibility تعترض ضغط
  زري رفع/خفض الصوت، تغيّر مستوى الصوت الحقيقي عبر `AudioManager`،
  وتعرض شريطًا عائمًا (overlay) خاصًا بدل واجهة النظام.
- `overlay_volume.xml`: تصميم الشريط الزجاجي (مسار + تعبئة).
- `MainActivity.kt`: شاشة بسيطة لتفعيل صلاحية Accessibility المطلوبة.

## خطوات التشغيل
1. افتح مجلد المشروع في **Android Studio** (Open an existing project).
2. انتظر حتى ينتهي Gradle Sync تلقائيًا (يحتاج إنترنت أول مرة لتحميل
   المكتبات).
3. وصّل هاتفك أو شغّل محاكي (Emulator)، ثم اضغط **Run ▶**.
4. عند فتح التطبيق لأول مرة: اضغط "تفعيل صلاحية Accessibility"،
   وفعّل "تحكم الصوت الزجاجي" من قائمة الإعدادات التي تفتح.
5. ارجع للتطبيق — إذا رأيت "✅ الخدمة مفعّلة" فكل شيء جاهز.
6. اضغط أزرار الصوت الفعلية في الهاتف — سيظهر الشريط الزجاجي بدل
   شريط أندرويد الافتراضي.

## توليد ملف APK
في Android Studio: **Build → Build Bundle(s) / APK(s) → Build APK(s)**
سيظهر رابط لملف APK الجاهز للتثبيت مباشرة.

## للنشر على Google Play
يحتاج الأمر حساب مطوّر Google Play (رسوم ٢٥$ لمرة واحدة)، ثم رفع نسخة
**AAB** موقّعة (Build → Generate Signed Bundle) عبر Play Console.
بما أن التطبيق يستخدم Accessibility Service، ستطلب غوغل عند المراجعة
توضيح سبب استخدامها (تخصيص شريط الصوت) — وهذا استخدام مقبول ومعروف.

## ملاحظات مهمة
- الصلاحية المطلوبة (`BIND_ACCESSIBILITY_SERVICE`) حساسة، ولا تُفعَّل
  تلقائيًا — المستخدم يوافق عليها يدويًا من الإعدادات.
- يمكنك تخصيص شكل/حجم/لون الشريط من `overlay_volume.xml` و
  `drawable/track_glass_bg.xml` و `drawable/fill_glass_bg.xml`.
- التطبيق يستهدف الحد الأدنى Android 7.0 (API 24) فأعلى.
